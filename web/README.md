# Cityverse — фронтенд

Next.js + wagmi + viem + RainbowKit. Подключение кошелька, список мест, баланс $CITY и все действия
из UI: **claim** дохода, **маркетплейс** (выставить/снять/купить) и **Harberger** (самооценка,
налог, принудительный выкуп). Работает с локальным `anvil`.

## Запуск локально

Нужно 3 терминала.

**1. Локальная сеть (anvil):**

```bash
anvil
```

**2. Деплой контрактов в anvil** (из корня репо; ключ — дефолтный тестовый account#0 anvil, не секрет):

```bash
forge script contracts/script/Deploy.s.sol:Deploy \
  --root contracts \
  --rpc-url http://127.0.0.1:8545 \
  --broadcast \
  --private-key 0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80
```

Адреса контрактов детерминированы (account#0, nonce 0..4) и уже прописаны в `lib/contracts.ts`.

**3. Фронтенд:**

```bash
cd web
npm install
npm run dev
```

Переменные окружения для локального запуска не нужны (используем injected-кошелёк, без WalletConnect).

Открой http://localhost:3000.

## Кошелёк

- Поставь MetaMask или Rabby.
- Добавь сеть: RPC `http://127.0.0.1:8545`, chainId `31337`.
- Импортируй тестовый аккаунт anvil (он печатает приватные ключи при старте) — у account#0
  на руках все засеянные места, у остальных — нет, удобно проверять «мои/чужие».

## Claim дохода

Доход капает по времени. На anvil метки блоков идут по реальным часам, так что небольшой доход
накопится сам. Чтобы увидеть заметную сумму сразу — промотай время вперёд (например, на сутки):

```bash
cast rpc evm_increaseTime 86400 --rpc-url http://127.0.0.1:8545
cast rpc evm_mine --rpc-url http://127.0.0.1:8545
```

Обнови страницу — «Накоплено» подрастёт. Кнопка «Забрать доход» есть на твоих местах (нужно быть
подключённым как владелец — account#0 anvil). После подтверждения транзакции баланс $CITY вырастет,
а накопленное обнулится.

## Маркетплейс

На своём месте: поле цены + «Продать» (две транзакции — `approve` NFT, затем `list`; место уходит
в escrow). На выставленном чужом месте — «Купить за N $CITY» (тоже две: `approve` $CITY, затем `buy`).
Свой листинг можно «Снять с продажи».

Чтобы что-то **купить**, у покупателя должен быть `$CITY` (он появляется только из `claim`). Для демо:
сначала накопи и забери доход, затем можешь купить даже собственный листинг (транзакция пройдёт),
либо переведи $CITY на другой anvil-аккаунт и покупай с него.

## Harberger (принудительный выкуп)

Место может быть в одном из трёх состояний: на руках / в листинге / под Harberger — карточка
показывает действия по контексту.

- **Под Harberger** (своё место на руках): задай самооценку и депозит → «Под Harberger». Место уходит
  в escrow, начинает капать налог из депозита.
- **Своё под Harberger:** «Пополнить» депозит (продлить «горючее») или «Забрать из Harberger»
  (нельзя в дефолте — сперва пополни).
- **Чужое под Harberger:** «Выкупить за N» — платишь текущую цену владельцу и сразу задаёшь свою
  самооценку и депозит.

Демо дефолта («плати налог или потеряешь»): зарегистрируй место с маленьким депозитом, промотай
время так, чтобы налог его съел — карточка покажет бейдж **дефолт**, «Выкуп сейчас: 0», и любой
сможет забрать место за 0.

```bash
# промотать время (налог 10%/год; чтобы съесть депозит = цене, нужен ~год):
cast rpc evm_increaseTime 31536000 --rpc-url http://127.0.0.1:8545
cast rpc evm_mine --rpc-url http://127.0.0.1:8545
```
